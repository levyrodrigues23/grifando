## Scope

Whole app shell and every route (dashboard, today, write, technical, explain-code, interview,
exercises, mistakes, vocabulary). Mode: Operate. Primary ritual: short daily session.

## Direction contract

THESIS: A writing coach set like a warm editorial spread: each screen is one "spread" with a
whisper-weight headline and a narrow serif standfirst, not a grid of dark same-size cards.
Refuses the dashboard-of-cards default and the old dark ember theme.

OWN-WORLD: User-pinned style reference. Canvas cream #faf9f6, linen #f1eee9 bands, white
#ffffff cards with #dedbd6 hairline, ink #111111 text, graphite #585858 secondary. Inter 300
display (80/54/40px, tight tracking), Inter 400 body, Source Serif 4 300 for the learner's own
prose and standfirsts, JetBrains Mono 12px uppercase +1.2px tracking for tags and metadata.
4px radius everywhere, black filled primary button, no shadows, no gradients, no dividers
between sections (tone shifts + 64-96px spacing). Electric violet #0007cb only for focus and
for mistake marks.

STORY: The learner opens the app, sees today's prompt as the headline-sized invitation, starts
the session, writes, and reads their own text back as a proofed page.

FIRST VIEWPORT: Top bar (wordmark left, tab-underline nav, Focus Music, black "Start today").
Dashboard hero: left 60% today's prompt set at display size in Inter 300; right column the
streak line and the black start button. Linen band below with progress figures.

FORM: Signature move: "the proofed page" — the learner's text in Source Serif with violet
underlined mistake marks and numbered mono marginal notes matching the mistake list. Pinned
direction (user-supplied reference), no roll. seed: none (unavailable)

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
